# 配音、字幕与原创声轨

本工程使用 `zh-CN-YunxiNeural` 中文神经语音，通过 `edge-tts` 访问公开在线语音端点。云环境测试已真实返回 MP3；不是预置的假配音或静音占位文件。该端点的持续可用性由服务提供方决定；项目不包含、输出或要求账户密钥。使用者应自行确认其发布场景适用的服务条款。

## 复现

```sh
python -m pip install edge-tts numpy
python scripts/audio.py
python scripts/voiceover.py
```

`voiceover.py` 读取 `data/narration.json`，按72段独立生成缓存，自动使用继承的 `HTTPS_PROXY`。每段使用真实返回的 WordBoundary 时标，先保留完整话音，仅移除尾部静音；不足时槽时留出呼吸，超出时以 FFmpeg `atempo` 保持音高压缩时长。超过1.4倍的段落会停止报错，不会偷偷丢字。生成 `output/voice-status.json` 留存每段测量时长与时间伸缩比例。

- `output/narration.wav`：48 kHz、单声道、600秒完整旁白。
- `data/subtitles.json`、`subtitles.srt`：来自服务返回词边界、经过同一时长换算的字幕；单条为短句，避免塞满全屏。语音服务的自动词边界会有少量感知误差；未冒称经过人工逐帧声学校对。
- `output/soundtrack.wav`：48 kHz、立体声、600秒原创程序化配乐和音效。
- `output/mix.wav`：旁白与配乐混音，旁白区间进一步降低背景音乐；最终以 FFmpeg loudnorm 统一到约 -18 LUFS、真峰值上限 -1.5 dBTP。

## 音乐与音效许可

`scripts/audio.py` 中的音高、和声、音序、包络、噪声与机械脉冲均为本项目原创程序化合成；未使用任何第三方录音、采样或已知曲调。这里的音色只承担纪录片情绪设计，不声称复原任何时代的真实音乐。战争、疾病、殖民暴力相关段落使用克制低频与缓慢音色，不设娱乐化胜利音效。

声轨采用12章不同的音色/节律计划：早期城市低音铺底，古代网络柔和弦音，海洋段宽阔持续音，科学段精细音序，工业段低幅机械脉冲，结尾收敛为沉稳和声。每章局部音型由确定性种子生成，可完全复现。

## 更换真人或正式授权语音服务

以 `data/narration.json` 的 `id` 为文件名准备每段话音，保留源录音及词/句边界元数据；或修改 `fetch()` 接入拥有使用权的服务。再用相同槽位合成与字幕时标转换流程。若在线服务不可用，脚本会真实失败并保留已完成缓存，不会以无旁白版本覆盖有声成片的名称。
