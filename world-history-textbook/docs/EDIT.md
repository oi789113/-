# 本版剪辑约定

- 范围以用户提供的课本第1—21课为准，并明确确认结束于1871年。
- 49镜各6秒，合计294秒。按七单元而非全球单一连续年代编排；同代与跨代回顾均由历史年代牌说明。
- 固定年代牌、课次、事件字幕、意义字幕，避免转场期间文字被镜头移动。
- 不制作丝绸之路或贸易网络专题，保留教材要求的新航路和殖民掠夺。
- 不含音乐、音效、人声或任何音轨。字幕烧录且只出现一套；SRT为独立辅助文件。
- 法典与制度讲述其作用及适用限制；革命兼顾制度影响与被排斥群体。理论评价与历史事实区分。
- 37个场景函数与12个地理构图交错，不复用旧视频。光点、方向线和场景图像均不宣称精确考古复原。
