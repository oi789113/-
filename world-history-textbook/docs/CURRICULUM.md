## 内容取舍

- 删除丝绸之路、地中海贸易、印度洋贸易、跨撒哈拉贸易和白银贸易等独立网络段落。新航路、殖民征服与强迫迁移仍保留，因为它们属于照片中的第14—15课。
- 不再单列原版中的中国秦汉唐宋、蒙古帝国、黑死病、科学革命、启蒙沙龙、海地革命等扩展篇章。必要的跨文明影响只在教材对应内容中简述。
- 第22课为唱响《国际歌》的活动课，依照用户“无音乐、无人声”的要求，不另做歌曲或演唱段落。
- 影片按教材单元组织，不是每秒对应连续历史年份；例如西欧中古与拜占庭、日本各有不同的时间窗口，均以画面年代为准。

## 重点历史意义

| 内容 | 影片说明 | 必要限定 |
| --- | --- | --- |
| 《汉谟拉比法典》 | 早期法律遗存，反映王权和等级 | 不是世界第一部法律，也不是现代意义的平等法典 |
| 《十二铜表法》 | 法律公开成文，限制任意解释 | 仍保留身份与性别不平等；古代传承资料有局限 |
| 《罗马民法大全》 | 系统整理罗马法，影响后世大陆法 | 核心编纂于529—534年，后续新律继续形成 |
| 《权利法案》 | 限制王权、保障议会权利 | 君主立宪制逐步发展，并非1689年立即成为现代普选民主 |
| 《独立宣言》与美国宪法 | 独立、权利原则、联邦制和分权制衡 | 奴隶制妥协、女性和其他群体的排斥仍在 |
| 法国革命与《人权宣言》 | 冲击特权和专制，提出自由与法律平等 | 权利宣称与实际政治、殖民及性别限制须区分 |
| 《拿破仑法典》 | 统一民法、保障财产权、巩固部分革命成果 | 保留父权与妇女法律地位限制；战争扩张另行呈现 |
| 工业革命 | 能源、资本、机器、劳动组织共同改变生产 | 不把工业革命归于一位发明家或单项发明 |
| 马克思主义、第一国际与巴黎公社 | 理论形成、国际组织与政治实践相连 | 理论主张、可核实事件与历史评价分别表述 |
