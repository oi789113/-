# 无人声版的声音与字幕

用户要求无任何人声，依靠字幕与动画讲述从两河流域到马克思主义形成时期的历史。本版因此不调用任何TTS，不采集人声，不使用旧版混音。

`scripts/audio.py` 只合成确定性的正弦波、谐波与噪声，生成原创音乐及机械、翻页、风声等示意音效。`output/audio-provenance.json` 记录程序与PCM源文件摘要。交付源码不含配音缓存。

最终合成只映射 `soundtrack.m4a` 的音轨。增量渲染即使读取旧版母片，也只读取视频流，所有中间视频使用 `-an`。验收比较最终音轨与纯音乐源的解码PCM摘要，确认未混入其他声音。

72段叙事字幕每段对应一个镜头，按画面阅读安排，不再依赖口播时间。SRT保留毫秒时间；Canvas按60FPS帧驱动。增量输出使用ASS，格式的百分之一秒精度造成的边界偏差低于一帧。每镜头为完整的一至两个句子，无打字机效果，无旁白缺失提示。

`narration.md` 为兼容初始交付文件清单而保留的阅读脚本，内容与 `captions.md` 相同；它不是已录制旁白。`data/narration.json` 同样仅为原引擎接口兼容别名。
